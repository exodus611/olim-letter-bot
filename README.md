# Бот «Что за письмо?» — израильские официальные письма по-русски

Пользователь фотографирует письмо (Битуах Леуми, налоговая, банк, ирия, купат холим, суд,
Хоцаа ле-Поаль…). Бот отвечает четырьмя сообщениями:

1. **Разбор** — от кого, тип письма, суть простыми словами, суммы/номера дел, **срок и сколько
   осталось дней**, пошаговый план (что / когда / как), варианты (рассрочка, возражение, скидка),
   что будет, если игнорировать, права, о которых человек может не знать, проверка на мошенничество.
2. **Проверенные контакты** — телефоны, часы, языки, сайт и онлайн-кабинет ведомства + «спасательные
   круги» (бесплатный адвокат Минюста, Коль Зхут по-русски, 1299). Кнопки: «Специалист», «Уже сделал», оценка.
3. **Черновик ответа на иврите** с плейсхолдерами + перевод.
4. **Словарик** терминов из письма.

Плюс: **напоминания о сроке** за 7 дней, за 2 дня и в день срока; многостраничные письма альбомом;
кредиты, рефералка, оплата Stars, сбор лидов для партнёров, админ-статистика.

## Чем это отличается от «просто загрузить в Gemini»

| | Gemini / ChatGPT напрямую | Этот бот |
|---|---|---|
| Телефоны и ссылки | генерирует, регулярно выдумывает | **только из проверенной базы** (`knowledge.py`), модели запрещено их писать, а просочившиеся вычищаются кодом |
| Сроки | «обычно 30 дней» | считает конкретную дату по закону (возражение по арноне 90 дн., Хоцаа ле-Поаль 30 дн., медкомиссия 60 дн. …) и **напоминает сам** |
| Мошенничество | если спросить | проверяет каждое письмо по известным схемам (SMS про посылку/штраф, «возврат от Битуах Леуми») |
| Права репатрианта | если спросить | подсказывает скидки/льготы по ситуации |
| Специалист | нет | кнопка → лид русскоязычному адвокату/бухгалтеру (партнёрская монетизация) |
| Порог входа | нужно знать, что это возможно, и уметь спросить | сфоткал → получил |

## Запуск за 10 минут

1. [@BotFather](https://t.me/BotFather) → `/newbot` → токен. Там же заполни `/setdescription`, `/setabouttext`, `/setuserpic`.
2. Ключ Gemini (бесплатно, без карты): https://aistudio.google.com/apikey
3. Свой user_id: [@userinfobot](https://t.me/userinfobot).
4. ```bash
   cd olim-letter-bot
   cp .env.example .env        # заполни BOT_TOKEN, GEMINI_API_KEY, ADMIN_IDS
   pip install -r requirements.txt
   python test_letter.py --demo   # проверка разбора без Telegram
   python bot.py
   ```
5. Напиши боту `/start` и пришли фото письма.

## Настройки (`config.py` / `.env`)

- `GEMINI_MODEL` — `gemini-2.5-flash` по умолчанию (бесплатный тариф). Можно поставить более новую Flash-модель.
- `GEMINI_THINKING_BUDGET` — 1024 по умолчанию: модель «думает» перед ответом, точнее с датами и суммами.
  0 — быстрее и экономнее.
- `LEAD_CHAT_ID` — id Telegram-группы, куда падают лиды (добавь туда бота и партнёров).
- Экономика: 3 бесплатных разбора, +3 за друга, пакеты 10/30/100 за 50/120/300 ⭐.

## База знаний — как поддерживать

`knowledge.py` — сердце продукта. Контакты проверены по gov.il, btl.gov.il, kolzchut.org.il и сайтам
муниципалитетов на сентябрь 2026. Раз в 2–3 месяца стоит:
- прозвонить/проверить 5–6 главных номеров (*6050, *4954, *2994, *3450, *35592, *6405);
- добавить ведомства, которые чаще всего всплывают в `/stats` → «Топ ведомств»;
- по фидбеку «👎» смотреть, где модель ошибается, и уточнять правила в `procedures`.

Добавить ведомство = добавить ключ в `ORGS` (контакты + процедуры со сроками). Модель автоматически
получит его в промпт, а бот — в блок контактов.

## Хостинг

Long polling — не нужен домен и белый IP.
- **Oracle Cloud Always Free** (ARM-виртуалка, бесплатно навсегда) — лучший вариант
- Fly.io / Railway — бесплатных кредитов хватает на маленького бота
- VPS за $3–5/мес (Hetzner, Contabo)

```bash
sudo tee /etc/systemd/system/letterbot.service >/dev/null <<EOF
[Unit]
Description=Olim letter bot
After=network.target
[Service]
WorkingDirectory=/home/ubuntu/olim-letter-bot
ExecStart=/usr/bin/python3 bot.py
Restart=always
RestartSec=5
[Install]
WantedBy=multi-user.target
EOF
sudo systemctl enable --now letterbot
```

## Лимиты

- Бесплатный тариф Gemini Flash — порядка 1 000–1 500 запросов/сутки на проект → ~300–500 активных
  пользователей в день. Дальше платный тариф: один разбор стоит доли цента.
- SQLite держит десятки тысяч пользователей. Дальше — PostgreSQL.
- Фото не сохраняются на диск — живут в памяти только на время запроса.

## Юридические мелочи

- Дисклеймер «не юридическая консультация» есть в каждом разборе — не убирай.
- Лиды содержат телефон — это персональные данные. Пользователь даёт его сам, явно, с объяснением
  зачем. Партнёрам уходит только тип письма/сумма/срок, без фото.
- Положи в about бота ссылку на короткую политику конфиденциальности (страница на Telegraph).
